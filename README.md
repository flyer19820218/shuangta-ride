# 雙塔騎行助手（shuangta-ride）

富貴角 → 鵝鑾鼻的單車導航網頁，手機瀏覽器直接開，不用安裝、不用 API key。

網址：https://flyer19820218.github.io/shuangta-ride/

## 功能

- **導航**：即時定位，吸附到路線上，顯示已騎／剩餘里程、離路線距離、下一個補給點、預計到達時間、保持亮屏。
- **地圖朝前**：定位後地圖會自動轉，讓「前進方向」永遠在螢幕上方，我在畫面偏下（前方看得遠），縮放約 16。路線上用前方約 150 m 的路線方向（不受 GPS 抖動影響），偏離路線時改用 GPS 行進方向；轉動有平滑處理、每秒最多更新一次。按「地圖：朝前／北上」或右上角指北針可切換，設定會記住。手動拖動地圖會暫停跟隨。
- **回到路線（迷路用）**：離開路線超過 80 m 會出現卡片，顯示方位箭頭、距離，並在地圖畫橘色虛線指向路線上前方約 150 m 的點（不用網路）；連網可再按「規劃回去的路」，在地圖畫出實際騎法並列出中文轉彎提示。「跟隨」只是讓地圖跟著你移動，不是導航。
- **補給**：參考 GPX 內的 68 個點（7-11、全家、萊爾富、OK、休息站）離線可用；可連網補查前方 40 km 的便利商店、飲水點、公廁，結果存在手機。
- **海拔**：全程／前方 30 km 海拔圖，標出補給點與目前位置。
- **路線**：可切換的改道段（淡江大橋、台南外圍繞行），淡江大橋預設啟用、台南外圍繞行預設關閉（使用者決定走原 GPX 的台南路線），並顯示新舊距離。
- **在家測試**：「路線」分頁的模擬位置可以不用 GPS 測整個流程，或網址加 `?sim=120`（模擬在 km 120）；「模擬離開路線」滑桿可以測「回到路線」卡片。

## 檔案結構

| 檔案 | 作用 |
| --- | --- |
| `index.html` | 畫面與樣式 |
| `app.js` | 地圖、定位、補給、海拔圖、改道段等畫面邏輯 |
| `leaflet-rotate.js` | 地圖旋轉外掛 leaflet-rotate 0.2.8（GPL-3.0，原樣放進來，不要改） |
| `core.js` | 純計算（距離、吸附軌跡、爬升、補給排序），不碰 DOM，可在 node 測試 |
| `route.json` | 路線資料，**由 `tools/gpx2json.py` 產生，不要手改** |
| `tools/detour_segs.json` | 改道段「預先驗證」的路線點（淡江大橋、台南），由 `gpx2json.py` 嵌進 `route.json` |
| `sw.js` | 離線快取（Service Worker） |
| `tools/gpx2json.py` | GPX → `route.json` |
| `tests/core.test.js` | `core.js` 的單元測試 |

## 常用指令

```bash
node tests/core.test.js                                    # 跑測試
python3 tools/gpx2json.py 來源.gpx route.json              # 換路線時重新產生資料
python3 -m http.server 8000                                # 本機預覽 http://localhost:8000
node tools/route2gpx.js 雙塔.gpx                           # 輸出車錶用 GPX（預設只開淡江大橋；加 danjiang tainan 可指定改道段）
```

## 修改規則（請 AI 協助修改時務必遵守）

1. 動手前先讀完這份 README，不要憑印象改。
2. 一律輸出**完整檔案**，不要只給片段。
3. `route.json` 不手改；要調整改道段，改 `tools/gpx2json.py` 的 `detours`（錨點、說明）或 `tools/detour_segs.json`（路線點）後重新產生。
4. 改了 `core.js` 就要跑 `node tests/core.test.js`，全部通過才能 commit。
5. 所有顯示給使用者的文字用繁體中文。
6. 來自 OSM／路由服務的文字（店名等）一律用 `esc()` 跳脫後才能放進 `innerHTML`。
7. 改了 `app.js`、`core.js` 之後，把 `index.html` 裡的 `?v=` 和 `sw.js` 的 `VER`、`SHELL` 內的 `?v=` 一起加一（目前是 6）（GitHub Pages 會讓瀏覽器快取約 10 分鐘，版本參數可讓手機立刻拿到新版）。

## 資料與限制

- 路線來源：網路上的參考 GPX《2023 TWB 雙塔520路徑規劃》（2023 年版，走關渡大橋）。
- **淡江大橋**（2026-05-12 通車）：2026-11-11 用 routing.openstreetmap.de 單車路由實測，淡水（km 15）到八里（km 34）為 10.1 km，比原路線繞關渡的 19.0 km 短約 9 km，路線已預先存進 `route.json`，不需連網。
- **台南外圍繞行**：同日實測 47.0 km（原路線 32.2 km，多約 15 km），離台南市中心最近約 7.4 km（原路線約 2.7 km），經過西港、新市、歸仁。預設**關閉**（走原 GPX 路線），可在「路線」分頁開啟。
- 以上都是「路由服務算出來的路線」，**不是現場勘查**：橋上自行車道的進出動線、路況與車流請以現場為準。
- 補給資料來自參考 GPX 與 OpenStreetMap，可能過時或漏登，店家營業時間請以現場為準。長距離段務必多帶水與行動糧。
- 地圖圖磚、路由、Overpass 都是免費公共服務，流量大時會慢或失敗；沒訊號時，路線、補給點、海拔、導航仍可使用（地圖底圖只有看過的區域有快取）。
- 地圖旋轉：leaflet-rotate 的 `bearing` 是「地圖順時針轉的角度」，要讓行進方向朝上要設 `360 - 行進方位`（程式已包在 `setBearingSafe`）；沒載入外掛時自動退回北上。
